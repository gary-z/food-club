# Best Models

NOTE: All LLs below are evaluated on modern (post-legacy) data only (1193 days,
5965 arenas) unless otherwise noted. Legacy/modern split used for train/test.
Baseline (uniform random): ln(0.25) = -1.38629


## Model 1: Bulk Fav Baseline

Modern LL: -1.06493

### Pseudocode

```
$wo = min(floor((221 - $pirate->weight) / 2), 7);
$strength = $pirate->strength;
for ($i = 0; $i < $na; $i++) {
    $strength -= rand(1, $wo);
}
$upper = max(1, 112 - $strength);
$reduction = floor($upper / 15);
$upper = max(1, $upper - $nf * $reduction);
$time = 0;
for ($i = 0; $i < 4; $i++) {
    $time += rand(1, $upper);
}
$time = floor($time / 14);
// Lowest time wins. Ties: later position wins.
```

### Parameters
- BASE = 112, FAV_DIV = 15 (bulk), N_ROLLS = 4, DIVISOR = 14, MAX_EFFECT = 7

### Known gaps
- Over-predicts weak pirates with allergies (Crossblades +2.3%, Puffo +2.6%)
- Under-predicts Ogletree (-2.8%)
- Weight only matters via wo = min(floor((221-weight)/2), 7) — confirmed by NN

## Model 5: PosMul + Quant + Later-Wins + Allergy-After (2026-03-17)

Modern LL: -1.06317 (delta +0.00313 vs Model 2, matches Model 4)

### Pseudocode

```

for ($i = 0; $i < 5; $i++) {
```

  suggesting the allergy-after ordering is the key structural improvement.


## Model 4: Iterative Fav + Allergy-After (2026-03-17, current best hand-rolled)

Modern LL: -1.06314 (delta +0.00178 vs Model 1)

### Pseudocode

```
$wo = min(floor((221 - $pirate->weight) / 2), 6);
$life = $pirate->strength;
// Allergy damage applied AFTER fav reduction
$upper = max(1, 120 - $life);
for ($i = 0; $i < $nf; $i++) {
    $upper -= floor($upper / 16);
    $upper = max(1, $upper);
}
for ($i = 0; $i < $na; $i++) {
    $upper += rand(1, $wo);     // allergy increases die after fav
}
$time = 0;
for ($i = 0; $i < 6; $i++) {
    $time += rand(1, $upper);
}
$time = floor($time / 22);
// Lowest time wins. Ties: later position wins.
```

### Parameters
- BASE = 120, FAV_DIV = 16 (iterative), N_ROLLS = 6, DIVISOR = 22, MAX_EFFECT = 6

### Key structural changes from Model 1
1. Iterative fav: each fav reduces die by floor(upper/16), recomputed each step.
   Strong pirates (small upper) get diminishing fav benefit per food.
2. Allergy-after: allergy damage adds to the die AFTER fav reduction, not before.
   Decouples the two effects, fixing over-prediction of weak allergic pirates.
3. Both changes were guided by NN diagnostic analysis showing M1 over-predicts
   fav benefit for strong pirates and over-predicts allergy penalty for weak pirates.

## Model 4 + Odds Prior (2026-07-29, best overall predictor)

Modern LL: -1.06177 (delta +0.00137 vs Model 4, +0.00100 vs the NN reference)

Not a game model — Model 4 blended with the information contained in the opening
odds. Only usable for prediction, not for reverse engineering the engine, and only
for arenas whose odds are already published.

### Pseudocode

```
// 1. odds -> interval for the odds maker's own probability
//    N=2  -> (1/3, 1]      (clamped from below)
//    N=13 -> (0, 1/13]     (clamped from above)
//    else -> (1/(N+1), 1/N]
// 2. narrow the four intervals by arc consistency on sum_i p_i = 1
//    repeat: hi_i = min(hi_i, 1 - sum_(j!=i) lo_j)
//            lo_i = max(lo_i, 1 - sum_(j!=i) hi_j)
// 3. p_odds_i = lo_i + t*(hi_i - lo_i), with t solving sum_i p_odds_i = 1
// 4. blend, then renormalise over the arena
//    p_i ~ model_p_i^0.5 * p_odds_i^0.5
```

### Parameters
- a = 0.5 (chosen on legacy; legacy optimum 0.5, modern optimum 0.7, flat between)

### Notes
- Do NOT hard-clamp the model into the odds intervals: that scores -1.07125 on
  modern, worse than the model alone. The intervals bound the odds maker's belief
  p_om, not the true probability, so they are a prior and not a constraint.
- See statistical_findings.txt #48.
