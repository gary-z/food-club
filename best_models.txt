# Best Models

## Model 1: Current Best (2026-03-12)

Train LL: -1.07825
Test  LL: -1.06414
Baseline (uniform random): ln(0.25) = -1.38629

### Pseudocode

```
$wo = min(floor((221 - $pirate->weight) / 2), 7);
$strength = $pirate->strength;
for ($i = 0; $i < $na; $i++) {
    $strength -= rand(1, $wo);
}
$upper = max(1, 112 - $strength);
$reduction = floor($upper / 15);
$upper = max(1, $upper - $nf * $reduction);
$time = 0;
for ($i = 0; $i < 4; $i++) {
    $time += rand(1, $upper);
}
$time = floor($time / 14);
// Lowest time wins. Ties: later position wins.
```

### Parameters
- BASE = 112
- FAV_DIV = 15 (bulk reduction: all favs computed from original upper)
- N_ROLLS = 4
- DIVISOR = 14
- MAX_WEIGHT = 221
- MAX_EFFECT = 7

### Key mechanics
- Positive score (eating time): lower = faster = better
- Overlap foods (both fav and allergy for a pirate): count as allergy only
- Position tiebreak: when quantized scores tie, later position wins
- Allergy damage: reduce effective strength by rand(1, weight_offset) per allergy
- Weight offset: min(floor((221 - weight) / 2), 7). Orvinn (w=221) is immune.

### Known gaps
- Weak pirates (~str<70) systematically underperform model by ~3% relative
  (model over-predicts their upset chance). 20/190 H2H pairs significant at |z|>2,
  of which 15 have weak pirate underperforming (vs 5 overperforming).
- Captain Crossblades (s=66) is worst offender: 8.7% H2H vs Buck (model: 16%, p=0.0004)
- Orvinn (s=52) consistently overperforms model predictions
- Grid search over BASE, FAV_DIV, DIVISOR, MAX_EFFECT confirms these are optimal
- Structural alternatives tested (NonLinear upper, MulFav, MoreDice, UpperCap,
  StrBoost, Fixed fav) all worse than baseline

### Verified non-effects
- Arena identity: no effect (finding 6)
- Food slot position: no effect (finding 8)
- Weight beyond allergy formula: no effect (finding 13, re-confirmed)
- Pirate scores: independent across arena (finding 15)


## Model 2: PosMul (verified 2026-03-12)

Train LL: -1.07978 (best by train: b=109 f%=93 pp=6)
Test  LL: -1.06389 (best by test: b=107 f%=93 pp=8)

### Pseudocode

```
$wo = min(floor((221 - $pirate->weight) / 2), 7);
$strength = $pirate->strength;
for ($i = 0; $i < $na; $i++) {
    $strength -= rand(1, $wo);
}
$upper_base = max(1, floor((109 - $strength) * 0.93^$nf));
$pos_mul = (100 - $pos * 7) / 100;   // pos 0-3
$upper = max(1, floor($upper_base * $pos_mul));
$score = rand(1, $upper) + rand(1, $upper) + rand(1, $upper);
// Lowest score wins. Ties: random among tied.
```

### Parameters (verified grid search)
- BASE = 109 (best train) or 107 (best test)
- FAV_PCT = 93 (multiplicative: upper *= 0.93 per fav, iterative)
- N_ROLLS = 3
- POS_PCT = 6-8 (die shrinks 6-8% per position step)
- MAX_WEIGHT = 221
- MAX_EFFECT = 7

### Key mechanics
- Positive score (eating time): lower = faster = better
- No floor division / no quantization — raw score comparison
- Position directly shrinks die size (pos3 gets ~21% smaller die = faster)
- Random tiebreak among equal scores (not position-based)
- Multiplicative fav effect (each fav multiplies upper by 0.93)

### Notes
- Nearly identical fit to Model 1 (train gap ~0.002, test essentially equal)
- Uses position as a direct input rather than emerging from floor+tiebreak
- The position mechanism is arguably more natural for game code
- 3 rolls instead of 4; multiplicative favs instead of bulk subtraction
- Two different structural approaches converge on the same predictive power


## Model 3: Allergy-After with Iterative Fav (2026-03-16, updated)

Train LL: -1.07214
Test  LL: -1.08477 (baseline -1.08601, delta +0.00124)

### Pseudocode

```
$life = $pirate->strength;
$wo = min(floor((221 - $pirate->weight) / 2), 6);
// Allergy damage applied AFTER fav reduction (see below)
$upper = max(1, 124 - $life);
for ($i = 0; $i < $nf; $i++) {
    $upper -= floor($upper / 17);
    $upper = max(1, $upper);
}
for ($i = 0; $i < $na; $i++) {
    $upper += dice(1, $wo);     // allergy increases die after fav
}
$time = 0;
for ($i = 0; $i < 6; $i++) {
    $time += dice(1, $upper);
}
$time = floor($time / 22);
// Lowest time wins. Ties: later position wins.
```

### Parameters
- BASE = 124
- FAV_DIV = 17 (iterative: recompute floor each fav)
- N_ROLLS = 6
- DIVISOR = 22
- MAX_WEIGHT = 221
- MAX_EFFECT = 6

### Key change from Model 1
Allergy damage applied to the die AFTER fav reduction, not before. In Model 1,
allergy reduces strength before computing the die, inflating upper, which then
inflates the fav reduction (floor(upper/K)). This gave pirates with both favs and
allergies (Crossblades, Puffo, Lucky) a spurious bonus. Applying allergy after
decouples the two effects.


## Optimality Bounds (2026-03-16)

### Method
Self-entropy: for each arena, compute model's predicted win probs (p1..p4), then
E[LL] = sum(pi * ln(pi)). This is the best LL achievable if the model were exactly
the true data-generating process. The gap (real LL - self-entropy) measures total
model misspecification.

### Results on post-legacy data (1193 days, 5965 arenas)

| Model              | Self-entropy | Post LL  | Gap      |
|--------------------|-------------|----------|----------|
| Model 1 baseline   | -1.07405    | -1.06493 | +0.00912 |
| S1 iter fav        | -1.08261    | -1.06512 | +0.01749 |
| Model 3 allg-after | -1.06462    | -1.06371 | +0.00091 |

### Interpretation
- Model 3 has the tightest gap (0.00091) on post-legacy data — nearly optimal.
- Positive gaps (Model 1, S1) mean the model is underconfident: actual outcomes are
  more predictable than the model thinks, so real LL exceeds self-entropy.
- The self-entropy varies across models (-1.064 to -1.083), so it cannot be used as
  an absolute bound on the true optimum. It is model-dependent.
- The true optimum LL is unknown but must be >= max(real LL across all models).
  Best observed: -1.06371 (Model 3 on post data).
- Calibration analysis shows all models are well-calibrated (predicted vs actual win
  rates match within 1-2pp across all probability buckets). The [80-100%] bucket
  shows ~2pp overconfidence consistently. Total calibration LL cost is ~0.00013.
- Uniform random baseline: ln(0.25) = -1.38629. Our models capture >99.5% of the
  range from uniform to estimated optimum.

### Key caveat
Self-entropy is not the true optimum — it is the optimum *if* the model were correct.
A model with different structure could have different self-entropy. However, the
small gap for Model 3 (0.00091) and excellent calibration suggest we are very close.
