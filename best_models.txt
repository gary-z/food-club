5965 arenas) unless otherwise noted. Legacy/modern split used for train/test.

## Model 1: Bulk Fav Baseline

Modern LL: -1.06493

### Pseudocode

```
$wo = min(floor((221 - $pirate->weight) / 2), 7);
$strength = $pirate->strength;
for ($i = 0; $i < $na; $i++) {
    $strength -= rand(1, $wo);
}
$upper = max(1, 112 - $strength);
$reduction = floor($upper / 15);
$upper = max(1, $upper - $nf * $reduction);
$time = 0;
for ($i = 0; $i < 4; $i++) {
    $time += rand(1, $upper);
}
$time = floor($time / 14);
// Lowest time wins. Ties: later position wins.
```

### Parameters
- BASE = 112, FAV_DIV = 15 (bulk), N_ROLLS = 4, DIVISOR = 14, MAX_EFFECT = 7

### Known gaps
- Over-predicts weak pirates with allergies (Crossblades +2.3%, Puffo +2.6%)
- Under-predicts Ogletree (-2.8%)
- Weight only matters via wo = min(floor((221-weight)/2), 7) — confirmed by NN

## Model 5: PosMul + Quant + Later-Wins + Allergy-After (2026-03-17)

for ($i = 0; $i < 5; $i++) {

  (floor quantization + later-wins tiebreak). Converges to same performance as Model 4,
  suggesting the allergy-after ordering is the key structural improvement.


## Model 4: Iterative Fav + Allergy-After (2026-03-17, current best hand-rolled)

Modern LL: -1.06314 (delta +0.00178 vs Model 1)

### Pseudocode

```
$wo = min(floor((221 - $pirate->weight) / 2), 6);
$life = $pirate->strength;
// Allergy damage applied AFTER fav reduction
$upper = max(1, 120 - $life);
for ($i = 0; $i < $nf; $i++) {
    $upper -= floor($upper / 16);
    $upper = max(1, $upper);
}
for ($i = 0; $i < $na; $i++) {
    $upper += rand(1, $wo);     // allergy increases die after fav
}
$time = 0;
for ($i = 0; $i < 6; $i++) {
    $time += rand(1, $upper);
}
$time = floor($time / 22);
// Lowest time wins. Ties: later position wins.
```

### Parameters
- BASE = 120, FAV_DIV = 16 (iterative), N_ROLLS = 6, DIVISOR = 22, MAX_EFFECT = 6

### Key structural changes from Model 1
1. Iterative fav: each fav reduces die by floor(upper/16), recomputed each step.
   Strong pirates (small upper) get diminishing fav benefit per food.
2. Allergy-after: allergy damage adds to the die AFTER fav reduction, not before.
   Decouples the two effects, fixing over-prediction of weak allergic pirates.
3. Both changes were guided by NN diagnostic analysis showing M1 over-predicts
   fav benefit for strong pirates and over-predicts allergy penalty for weak pirates.
