## 3. Model-free bound: how good is a 2:1 bet, using ONLY the odds?
   sum_i p_om_i = 1 and p_om_j <= 1/N_j for j != i give
       p_om_i >= 1 - sum_(j!=i) 1/N_j = 1.5 - U      (for a lone 2:1)
       EV_i   >= 2*(1.5 - U) = 3 - 2U
